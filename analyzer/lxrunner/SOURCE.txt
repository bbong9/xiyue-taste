iOS adaptation:
- The fixed upstream preload is adapted for iOS; it is not byte-for-byte unchanged.
- Existing adaptations declare extended online quality identifiers and the
  host-private xiyueMusicFreeSearch operation.
- 2026-09-14: musicUrl response length changes from 2048 to 16384 characters
  to match LXNetworkPolicy.maximumURLBytes; native validation additionally
  enforces the UTF-8 byte limit. Scheme and network address checks remain.
- iOS supplies the native bridge globals required by the preload.
- A single WKWebView JavaScript context owns preload, user script, callbacks,
  timers, and request state for the runtime lifetime.
- No worker supervisor or alternate lx protocol is introduced.
- 容器运行器用的是同一份 iOS 改编版，未再改动。
